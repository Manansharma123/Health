# Sentiment Analysis Dashboard UI

A stunning, interactive web interface to visualize and explore sentiment analysis results.

##  Features

- **Modern Dark Mode Design** - Vibrant gradients, glassmorphism effects, smooth animations
- **Interactive Charts** - 15+ visualizations using Chart.js
- **Real-time Data** - Loads from CSV files generated by the notebook
- **Responsive Layout** - Works on desktop, tablet, and mobile
- **Search & Filter** - Interactive tables with search and sort functionality
- **Smooth Navigation** - Sidebar navigation with smooth scrolling

##  Quick Start

### Prerequisites

1. Run the Jupyter notebook (`notebooks/complete_analysis.ipynb`) to generate CSV files
2. Ensure the following files exist in `data/processed/`:
   - `sentiment_labeled_data.csv`
   - `brand_affinity_scores.csv`
   - `top_recommendations.csv`

### Running the Dashboard

**Option 1: Python HTTP Server (Recommended)**

```bash
cd ui
python3 -m http.server 8000
```

Then open: http://localhost:8000

**Option 2: Node.js HTTP Server**

```bash
cd ui
npx http-server -p 8000
```

Then open: http://localhost:8000

**Option 3: VS Code Live Server**

1. Install "Live Server" extension in VS Code
2. Right-click `index.html` → "Open with Live Server"

> **Important**: You must use a local server (not `file://` protocol) for CSV data loading to work properly.

### Adding New Charts

1. Add canvas element in `index.html`:
```html
<canvas id="my-new-chart"></canvas>
```

2. Create chart function in `app.js`:
```javascript
function createMyNewChart() {
  const ctx = document.getElementById('my-new-chart');
  new Chart(ctx, { /* config */ });
}
```

3. Call in `createAllCharts()` function

##  Troubleshooting

### Charts Not Displaying

**Issue**: Charts appear empty or don't render

**Solutions**:
1. Check browser console for errors
2. Verify CSV files exist in `data/processed/`
3. Ensure you're using a local server (not `file://`)
4. Check CSV file column names match expected format

### Data Not Loading

**Issue**: "No data available" messages

**Solutions**:
1. Run the Jupyter notebook first to generate CSV files
2. Check file paths in `app.js` match your directory structure
3. Verify CSV files are not empty
4. Check browser console for CORS errors

### Styling Issues

**Issue**: UI looks broken or unstyled

**Solutions**:
1. Clear browser cache
2. Check that `styles.css` is loading (Network tab in DevTools)
3. Verify Google Fonts are loading
4. Try a different browser

##  Responsive Design

The dashboard is fully responsive:

- **Desktop** (>1024px): Full sidebar, multi-column charts
- **Tablet** (768px-1024px): Narrower sidebar, single-column charts
- **Mobile** (<768px): Collapsible sidebar, stacked layout
